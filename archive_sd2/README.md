# Cấu hình SD2 lịch sử

Các file trong `configs/` tại đây dành cho thực nghiệm trước commit tái cấu
trúc. Các backup đã tạo vẫn đọc được bằng script đánh giá lịch sử. Notebook
chính và bảng V1/V2/V3 dùng SD1.5. Để chạy lại nguyên môi trường và mã của
thực nghiệm cũ, checkout commit sinh ra profile đó.
